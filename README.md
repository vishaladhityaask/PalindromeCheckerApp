# PalindromeCheckerApp

## Running Procedure
1. Start the application.
2. Enter a text or word.
3. The program reads the input using Scanner.
4. The string is reversed using a loop.
5. The reversed string is compared with the original string.
6. The program displays whether it is a palindrome or not.

## Flow of Project
User Input -> Reverse String -> Compare -> Display Result

## Objective
The objective of this project is to build a Java program that checks whether a given string is a palindrome.

## Topics Covered
- Java Basics
- String Handling
- For Loop
- If-Else Condition
- Scanner Class

## Use Case
This application helps users check whether a word or sentence is a palindrome.
